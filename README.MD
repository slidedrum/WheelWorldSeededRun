 # SeedMod
 
 This mod allows you to set a seed for all part drops, this includes part boxes and race rewards.  This does not impact static rewards or drops.

 If you do not use the same seed for the entire durration of a playthrough, your save will be marked as invalid.  This includes if you load your save without this mod installed.  This includes using this mod on a save that did not start with this mod installed.
